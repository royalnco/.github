### 🤖 AI-Driven Development & Organization Policy

본 GitHub Organization은 **AI(Claude 등)를 활용하여 대시보드 및 사내 솔루션/프로젝트를 개발하는 구성원**을 위해 회사 공식 계정으로 운영되고 있습니다. 사내 자산 보호와 체계적인 버전 관리를 위해 아래 운영 정책을 반드시 준수해야 합니다.

* **사내 산출물 중앙 집중화**
  * Claude를 활용하여 기획·제작한 모든 대시보드, 자동화 스크립트, 웹 애플리케이션 프로젝트는 반드시 **`royalnco` 조직(`https://github.com/royalnco`) 산하 저장소에 생성 및 저장**되어야 합니다.
  * 개인 계정에 코드를 보관하거나 외부 저장소로 반출하는 것을 엄격히 금지합니다.

* **보안 및 접근 통제**
  * 모든 프로젝트 저장소는 **비공개(Private)** 생성을 원칙으로 하며, 팀 단위 권한 통제를 적용합니다.
  * 소스코드 및 환경 변수 파일(`.env` 등) 내에 사내 DB 접속 정보, API Key, 시크릿 토큰이 커밋되지 않도록 철저히 관리합니다.

* **형상 관리 및 협업 규칙**
  * 기본 브랜치(`main`) 직접 커밋을 지양하고, 작업 브랜치 생성 후 PR(Pull Request)을 통한 머지를 권장합니다.
