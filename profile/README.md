### 💡 AI 업무 혁신 및 프로젝트 자산화 안내

본 GitHub Organization은 **AI 도구(Claude 등)를 활용하여 업무 자동화, 대시보드, 데이터 분석 도구 등을 제작하는 임직원**을 지원하기 위해 운영되는 회사 공식 계정입니다. 

AI를 통해 제작된 모든 결과물은 회사의 중요한 디지털 자산이며, 안전한 보관과 원활한 사내 공유를 위해 아래의 기본 원칙을 지켜주시기 바랍니다.

### 📋 프로젝트 등록 및 이용 수칙

1. **AI 제작 산출물의 공식 등록**
   * AI(Claude 등)의 도움을 받아 만든 모든 업무용 대시보드, 보고용 웹페이지, 자동화 도구는 반드시 **로얄앤컴퍼니 공식 GitHub(`https://github.com/royalnco`)에 저장소(Repository)를 만들어 등록**해야 합니다.
   * 개인 PC나 개인 계정에만 보관할 경우 담당자 부재 시 공유가 어렵거나 유실될 위험이 있으므로, 완성된 결과물은 회사 공식 저장소에 안전하게 보관해 주시기 바랍니다.

2. **사내 데이터 및 보안 정보 보호**
   * 모든 프로젝트 저장소는 외부인이 볼 수 없는 **비공개(Private)** 상태로 안전하게 운영됩니다.
   * 소스코드나 문서 내에 **회사 내부 비밀번호, 시스템 접속 계정, 고객 개인정보** 등이 직접 적히지 않도록 각별히 유의해 주시기 바랍니다.

3. **안전한 작업 및 버전 관리**
   * 기존에 잘 동작하던 프로젝트를 수정할 때는 작업 내용에 대한 백업과 변경 이력을 남겨두면 오류 발생 시 이전 상태로 안전하게 되돌릴 수 있습니다.
   * 프로젝트 생성, 권한 부여, AI 연동 과정에서 기술적인 지원이 필요한 경우 언제든지 **정보관리팀**으로 문의해 주시기 바랍니다.
